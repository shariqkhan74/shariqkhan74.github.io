---

## 🚀 Key Highlights & Features

### 🎨 Visual & UX Excellence
- **Sleek Obsidian & Slate Palette**: Dark-mode aesthetic with ambient mesh glows and subtle backdrop blurs.
- **Glassmorphic Bento Layouts**: Clean, modern cards with subtle gradient borders and smooth hover states.
- **Micro-Interactions & Fluid Animations**:
  - Intersection Observer scroll reveal animations.
  - Interactive skill progress meters with animated fills on scroll.
  - Interactive category project filtering with smooth transitions.
  - Copy-to-clipboard for email and telephone with custom toast notifications.
  - Active section scroll-spy indicator on desktop and mobile navigation.

### 📱 Full Multi-Device Responsiveness
- Optimized across all standard screen sizes (320px, 375px, 414px, 768px, 1024px, 1440px, 1920px).
- Mobile navigation drawer with backdrop blur, keyboard accessibility, and outside-click dismissal.
- Zero horizontal overflow and clean touch targets.

### 🔍 SEO & Web Standards
- **Structured Data (JSON-LD)**: Schema.org markup for `Person`, `WebSite`, and `ProfilePage`.
- **Open Graph & Twitter Cards**: Social media preview metadata.
- **Robots & Sitemap**: `robots.txt` and `sitemap.xml` for search engine crawling and indexing.
- **Accessibility (a11y)**: Semantic HTML5 elements (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`), ARIA attributes, visible keyboard focus indicators, and `prefers-reduced-motion` support.
